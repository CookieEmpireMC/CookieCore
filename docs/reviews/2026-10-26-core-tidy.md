## 3. Findings
No HIGH or MEDIUM findings. PERF-HIGH: none.

### LOW (follow-ups, no fix round)
- **L-1: F-12 covers quoted numbers only. Unquoted non-whole and out-of-range numbers are truncated silently.** `config/PluginSettings.java` `intOrDefault`, `Number` branch: `return n.intValue();`. `port: 3308.5` becomes `3308` with no problem. An unquoted Long outside int range wraps (`port: 4294970000` becomes `2704`, which passes the 1–65535 check). Not pinned by a test (the test would have to fail today; the lead's decision was to keep it out). Suggested fix: `if (raw instanceof Integer i) return i;` and parse every other value from its string form, reporting failures, so `3308.5` and `4294970000` are reported.
- **L-2: stale Javadoc in `api/CookieCoreApi.java:9`** still says "Declare `softdepend: [CookieCore]`". Consumers now declare `dependencies.server.CookieCore` in `paper-plugin.yml`. Owner: plugin-coder.
- **L-3: empty `cookiecore-libraries.properties` loads zero drivers silently.** `CookieCoreLoader.libraries()` throws a clear `IllegalStateException` for a missing file, but an empty file returns an empty list and the failure appears later as "JDBC driver ... not found; did CookieCoreLoader load it?". The descriptor test now asserts the exact two coordinates, so a regression fails the build; the runtime path is still less clear than it could be. Suggested fix: throw in `libraries()` when the list is empty.
- **L-4: `Dependency(new DefaultArtifact(coordinates), null)`** passes a null scope. Not verified here whether Aether normalises it to the empty scope; the first Paper start will show it (see the human item).
- **L-5: behaviour change for admins who set `database.shutdown-timeout-seconds`.** The key is removed from `config.yml`, and a value an admin had set is now silently ignored (the constant is 10). The brief approves this (constant with the same value); mentioned so the PR notes it.
- **L-6 (documentation, not a bug): `PlayerDirectory.cachedPlayers()`** (F-14) still has only test callers; kept on purpose for now, noted in `architecture.md`.

## 6. In-game test guide (for the PR)
1. Start a Paper 26.3 server with the jar: clean boot, no "Could not load plugin" errors, the JDBC driver for H2 loads (the log has no "did CookieCoreLoader load it?").
2. `/cookiecore version` (with `cookiecore.admin.version`) shows the version, server name, `h2` and `connected`.
3. `/cookiecore reload` with a valid `config.yml` confirms with the pling sound; a bad value (e.g. `database.port: abc`) lists the problem and plays the error sound. With `database.type: mariadb` and `database.port: '3308'` in a test copy, a restart connects to port 3308 (F-12).
4. Join and quit: `plugins/CookieCore/data/core.mv.db` gains a row.
5. Install LuckPerms and confirm the server still loads (it is `required: false`); remove it and confirm the same.
